# 🍽️ Sabores del Mundo - Frontend

Proyecto final de diplomatura Fullstack basado en una página web de restaurante moderna y responsive.

La aplicación permite a los usuarios registrarse, iniciar sesión y realizar reservas de mesas de forma personalizada y segura.

---

# 🚀 Tecnologías utilizadas

- React
- JavaScript
- CSS3
- Responsive Design
- API del clima

---

# ✨ Funcionalidades

- Registro e inicio de sesión
- Validación de usuarios
- Reserva de mesas
- Edición de reservas
- Visualización personalizada de reservas por usuario
- Restricción de reservas los días domingo
- Consumo de API del clima
- Diseño responsive adaptable a dispositivos móviles

---

# 🔐 Seguridad y sesiones

Cada usuario puede visualizar únicamente sus propias reservas.

Si un usuario no ha iniciado sesión, el sistema redirecciona automáticamente al login para poder reservar una mesa.

---

# 📱 Responsive Design

La interfaz fue desarrollada para adaptarse correctamente a:

- Computadoras
- Tablets
- Dispositivos móviles
